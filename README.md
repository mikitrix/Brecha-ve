# Brecha VE

Dólar y euro BCV vs USDT en Binance P2P, brecha cambiaria y calculadora de ganancia.

Las tasas se actualizan solas cada 30 minutos con GitHub Actions (`.github/workflows/tasas.yml`). Fuentes: [DolarAPI](https://ve.dolarapi.com) y [CriptoYa](https://criptoya.com). Informativo, no es asesoría financiera.
